O QUE FOI FEITO:
1. Reconstrução completa da maquete (maquete.js) para carregar o modelo GLB real
   - exposicao-shopping.glb (12.8 MB, 75 malhas, 338.602 triângulos)
   - Modelo contém os 3 estandes em 3D completo (zero imagens estáticas)
   - Paçoca do Amor: coração de amendoins (1.613 peças), balcões, estrutura dourada
   - 7 Belo: mascote carta de baralho, prateleiras, pirulitos, donut, gummy bears
   - Poosh!: quarto de gelo, cama cryo-pod, árvore de Natal, neon

2. Espaço de shopping 3D (tudo em geometria 3D, zero imagens):
   - Piso de 200m² (22m × 12m) com zonas coloridas por estande
   - Paredes semi-transparentes com faixas neon na base
   - Teto com vigas estruturais e skylight central
   - ENTRADA decorada: pilares, arco dourado, colunas ornamentais, tapete vermelho, 
     cordas de veludo com estacas douradas, spotlights, placa ARCOR luminosa
   - SAÍDA decorada: moldura de porta, placa EXIT luminosa, setas no chão
   - Elementos de corredor: pilares shopping, bancos, vasos com plantas,
     totem informativo com tela, lixeiras

3. Interface do site:
   - Header com navegação: Vista Geral, Paçoca do Amor, 7 Belo, Poosh!
   - Botões de controle: auto-rotação, grade, etiquetas, medidas
   - HUD inferior: status interativo, dimensões, dicas, zoom +/-/reset
   - Painel lateral com informações detalhadas de cada estande
   - Etiquetas 3D flutuantes (ENTRADA, SAÍDA, nomes dos estandes, dimensões)
   - Tooltip no hover sobre estandes
   - Escala de referência (5m)

4. Funcionalidades interativas:
   - Câmera orbital com damping (girar, zoom, pan)
   - Clique nos estandes → câmera anima + info panel abre
   - Navegação por botões com animação suave de câmera
   - Auto-rotação toggleável
   - Grade toggleável
   - Etiquetas toggleáveis
   - Linhas de medição toggleáveis
   - Suporte a touch (mobile)
   - Tela de loading com barra de progresso do download do GLB

5. Tecnologias usadas:
   - Three.js (local, sem CDN) com PBR (environment map via RoomEnvironment)
   - GLTFLoader para carregar o modelo
   - OrbitControls para navegação
   - CSS glassmorphism com backdrop-filter
   - Google Fonts (Inter, Outfit)
